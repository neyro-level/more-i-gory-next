**Статус:** Active
**Версия пакета:** 1.5 Development Ready
**Дата:** 2026-09-10
**Стандарт:** AMS Product Development Standard 2.0 (эквивалентный numbered root canon)

## 1. Назначение

Эта папка — канонический комплект документов для разработки нового сайта «Море и Горы».

AI-агент перед изменением читает `AGENTS.md`, этот индекс, профильный canonical
документ и текущую задачу из `05_BACKLOG.md`. Весь пакет перечитывается только
для архитектурного или release-wide scope.

## 3. Источники evidence

Исторические документы и исследования используются как доказательная база, но не как параллельный source of truth:

- прежний `01_PROJECT_PASSPORT.md`;
- прежний `02_SITE_ARCHITECTURE.md`;
- прежний `03_DESIGN_SYSTEM.md`;
- прежний `04_SEO_PASSPORT.md`;
- прежний `05_TECHNICAL_ARCHITECTURE.md`;
- конкурентное исследование рынка инвестиционной курортной недвижимости;
- техническое конкурентное исследование SEO-, контентной и конверсионной архитектуры;
- Topvisor / Wordstat / SERP-срезы;
- transfer package действующего `moreigori.ru`.

Если evidence противоречит каноническому документу, реализация следует каноническому документу. Если обнаружено новое существенное доказательство, сначала обновляется соответствующий source of truth.

## 4. Статусы документов

- `Draft` — документ ещё обсуждается.
- `Active` — канонический источник истины.
- `Superseded` — заменён новой версией.
- `Deprecated` — больше не используется.

## 5. Правило работы AI

AI не имеет права:
- расширять scope без обновления PRD/Scope;
- менять URL-модель без обновления Product Structure;
- менять архитектурный контракт без ADR;
- добавлять CMS, БД, auth, runtime Next.js или крупные зависимости без отдельного решения;
- создавать SEO-страницы из фильтров;
- публиковать неподтверждённые финансовые показатели как факты;
- начинать задачу со статусом `BACKLOG`.

## 6. Текущая точка

Разработка начата через PR-00. Для PAGE-001..023 в `02_PRODUCT_STRUCTURE.md`
зафиксированы intent, H1, коммерческая роль, данные, доказательства, связи, CTA,
индексация и content gate. Публикация страницы всё равно запрещена, пока её
индивидуальный content gate не пройден.

Текущий маршрут исполнения и статус каждого эпика находятся только в `05_BACKLOG.md`.

- законченный первый экран для остальных PAGE-ID;
