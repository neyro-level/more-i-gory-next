# Море и Горы Next

Статический коммерческий сайт инвестиционного бюро курортной недвижимости.

## Локальная работа

```text
pnpm dev
pnpm verify
pnpm build
```

Каноническая документация проекта находится в [`docs/README.md`](docs/README.md).
Перед изменениями AI читает `AGENTS.md`, карту документации и только профильный
Source of Truth текущей задачи.

Production выпускается только отдельной командой владельца.
