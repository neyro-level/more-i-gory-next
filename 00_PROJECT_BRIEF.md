# Project Brief — «Море и Горы»

**Статус:** Active
**Версия:** 1.0
**Дата:** 2026-09-10
**Owner:** Product Owner / Architect

## 1. Project

«Море и Горы» — новый SEO-ориентированный сайт инвестиционного бюро курортной недвижимости на домене `moreigori.ru`.

## 2. Product Type

Коммерческий статический сайт + курируемый каталог проектов + аналитическая библиотека + квалифицирующая форма.

Проект не является массовым агрегатором недвижимости и не является Realty Platform в первом релизе.

## 3. Business Goal

Создать сайт, который:
- получает органический спрос по курортной и инвестиционной недвижимости;
- особенно глубоко покрывает Сочи и Крым;
- объясняет клиенту инвестиционную логику выбора;
- переводит посетителя от поискового запроса к проекту и персональному разбору;
- формирует доверие за счёт методики, источников, рисков и прозрачной экономики;
- генерирует квалифицированные обращения.

## 4. Users

Основной пользователь:
- покупатель / инвестор из Москвы и Московской области;
- рассматривает вложение в курортную недвижимость;
- не хочет самостоятельно разбирать десятки проектов;
- ожидает объяснения экономики, рисков, управления и выхода.

Вторичные рынки привлечения:
- Санкт-Петербург;
- Екатеринбург;
- Новосибирск;
- Ростов-на-Дону;
- Казань;
- Пермь.

Объектные регионы:
- Сочи;
- Крым;
- Архыз;
- Алтай.

## 5. Core Problem

Рынок перегружен:
- массовыми каталогами;
- одинаковыми обещаниями доходности;
- маркетинговыми процентами без полной net-экономики;
- слабым раскрытием downside;
- слабым объяснением оператора;
- почти отсутствующим сценарием выхода.

Пользователю сложно понять не «что купить», а «почему конкретный проект подходит его инвестиционной задаче».

## 6. Proposed Solution

Сайт строится как система принятия решения:

```text
поисковый спрос
→ регион / сегмент
→ инвестиционная логика
→ ограниченный пул проектов
→ инвестиционный паспорт
→ сравнение / аналитика
→ персональный инвестиционный разбор
```

Основное продуктовое обещание:

> Мы показываем только те проекты, для которых можем объяснить инвестиционную гипотезу, происхождение ключевых цифр, основные риски и сценарий выхода.

## 7. Expected Result

Первый крепкий релиз должен иметь:
- сильную главную;
- федеральный инвестиционный хаб;
- расширенное SEO-покрытие Сочи;
- расширенное SEO-покрытие Крыма;
- самостоятельные хабы Архыза и Алтая;
- курируемый каталог;
- 8–12 полноценных инвестиционных паспортов;
- методику;
- аналитические материалы;
- продуктовую страницу персонального разбора;
- корректную миграцию старых URL;
- быстрый статический production без Next.js runtime.

## 8. Constraints

- docs-first;
- solo + AI;
- SourceCraft — канонический git-контур;
- первый релиз — static export;
- production — Nginx;
- CMS, PostgreSQL, Prisma, auth и server runtime не входят;
- основной SEO-контент должен присутствовать в HTML без клиентского JavaScript;
- новый индексируемый URL создаётся только при доказанном интенте и самостоятельной ценности;
- финансовые, юридические и инвестиционные утверждения требуют источника, даты и статуса;
- клиентский JavaScript минимизируется;
- существующий live-сайт — визуальный и миграционный источник, но не архитектурный канон.

## 9. Existing Assets

Есть:
- действующий `moreigori.ru`;
- transfer package текущего дизайна;
- конкурентные исследования;
- Wordstat / Topvisor / SERP evidence;
- прежние проектные документы;
- визуальные ассеты;
- предварительная карта редиректов.

## 10. Unknowns

До публикации части контента необходимо дополнительно подтвердить:
- реальный ассортимент по городам и сегментам;
- методику отбора;
- источники операционных данных;
- модель брокерского вознаграждения и конфликт интересов;
- допустимые формулировки прогнозов;
- реальные подтверждаемые кейсы;
- фактическую работу компании в отдельных городах Крыма;
- финальную карту всех legacy URL и их ценность по Вебмастеру / ссылкам / трафику.
