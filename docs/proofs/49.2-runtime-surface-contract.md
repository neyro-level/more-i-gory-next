## Local contract

- install accepts only a valid 40-character SHA and existing tarball/sidecar;
- SHA-256 mismatch stops before extraction or symlink mutation;
- `RELEASE.json` must match artifact version 1, Next standalone layout, Node 24
  and the exact requested SHA;
- extraction uses a temporary incoming directory and an existing immutable
  release cannot be overwritten;
- `current` changes by atomic rename and the former target is retained as
  `previous`;
- preview Nginx owns TLS, noindex and Admin/API/static proxying;
- systemd pins loopback Node, staging contour and `JOBS_AUTORUN=false`;
- preview env validation pins the single DB and Timeweb S3 staging prefix.
