# TASK 49.1 — immutable staging artifact

**Mode:** code/build proof; preview installation remains TASK 49.O
**Builder:** off-host Linux, Node.js 24, pnpm 11.5.1

## Reproduced defect

The Linux Next.js standalone build was valid in its builder tree, but the old
packer converted pnpm's relative `node_modules/next` symlink into an absolute
`/workspace/.next/standalone/...` link. A fresh runtime container extracted the
archive and failed with `Cannot find module 'next'`.

## Fix contract

- copy standalone with `verbatimSymlinks:true`;
- reject every absolute or dangling symlink before archive creation;
- keep `server.js`, `.next/static`, `public` and the traced standalone tree;
- write `RELEASE.json` with artifact version, Node major and exact Git SHA;
- emit `<release>.tar.gz` and a SHA-256 sidecar;
- build and pack only outside `/opt/moreigory` and the runtime host.

## Acceptance

PASS on base `e4b0d006f279a1df9c788b826d151c7c6089545e`:

- actual Next.js standalone build completed in a Linux Node 24 builder;
- the fixed packer produced a 23 MB archive and valid SHA-256 sidecar;
- the packed `node_modules/next` link remained relative and resolved;
- Linux unit coverage passed, including the symlink portability case;
- a separate clean Node 24 container extracted only the archive, resolved
  `next`, started `server.js` and returned `200 {"ok":true}` from
  `/api/health/`.

Artifact install, public smoke and rollback are intentionally deferred until
the merged TASK 49.P runbook is used by TASK 49.O.
