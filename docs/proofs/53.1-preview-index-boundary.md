## Fixture remediation

The first live sitemap inspection exposed `/obekty/db-proof-published/`, a
synthetic record retained after the single-database smoke. Authenticated Payload
inspection confirmed exactly two reserved fixtures: `db-proof-published` and
`db-proof-draft`. Both were deleted, no matching rows remained, the preview
service was restarted to clear the stale in-memory sitemap cache, and the next
sitemap response contained zero URLs.

The code now rejects reserved `db-proof-*` and the three `preview-*` template
paths in the canonical sitemap filter. Regression tests cover the exclusion and
the exact 29-link navigation contract.

`.next/cache`; this also prevents normal tag revalidation. It did not invalidate
the HTTP/noindex proof, but TASK 53.3 must repair the writable runtime-cache
contract and repeat the affected cache/image/performance checks.
