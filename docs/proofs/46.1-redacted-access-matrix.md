## Secret-name coverage

Присутствуют группы имён для:

- deploy SSH alias/user/key/fingerprint;
- server identity, location и Timeweb server ID/name;
- application и PostgreSQL connection fields;
- Timeweb API token и его owner label.

Не присутствуют и намеренно не подставляются по аналогии:

- `MOREIGORY_STAGING_DATABASE_URL`;
- отдельные staging DB/user credentials;
- `PAYLOAD_SECRET` и `NEXT_PUBLIC_SERVER_URL`;
- revalidation secret;
- runtime `S3_*` names.

Их routing принадлежит TASK 46.2–46.3. Отсутствие этих names не меняет и не
блокирует подтверждённый доступ к существующим server/DB resources.

## Root SSH decision

Провайдерская карточка сервера сообщает, что password root SSH технически
разрешён. Канонический маршрут его не использует: alias `moreigory` входит как
`deploy`, а non-interactive sudo достаточен для systemd, env и release runbook.
Усиление root/password policy относится к credential hardening, а не требует
перевода текущих операций на root login.
