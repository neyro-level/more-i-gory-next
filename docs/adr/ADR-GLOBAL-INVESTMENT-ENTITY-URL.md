# ADR: Global Investment Entity URL

Status: Accepted
Date: 2026-09-24

## Context

Региональные project URL нестабильны: изменение географии или таксономии
потребовало бы переноса canonical и создало бы дубли одного объекта.

## Decision

Каждый опубликованный инвестиционный проект имеет один глобальный canonical:

```text
/obekty/{project}/
```

`/obekty/` — курируемый глобальный инвестиционный каталог. Регион, город и тип
являются атрибутами/фильтрами, но не частью canonical. Лоты не получают
самостоятельные индексируемые маршруты.

## Consequences

- project canonical не меняется при изменении региональной классификации;
- региональные страницы ссылаются на один паспорт проекта;
- filter/sort states canonical указывают на `/obekty/` и не индексируются.

## Revisit When

Только если модель продукта перестанет считать Project глобальной сущностью.
