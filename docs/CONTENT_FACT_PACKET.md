## H. Правило обработки ответа

1. Факт с источником и без конфликта → кандидат `FACT_PASS`.
2. Факт без достаточного evidence → `UNPUBLISHED_NO_FACT`.
3. Осознанно исключённая область → `DEFERRED_OUT_OF_RELEASE`.
4. Конфликт источников останавливает только соответствующую строку.
5. Ни один ответ не запускает production, публикацию или DNS cutover.
