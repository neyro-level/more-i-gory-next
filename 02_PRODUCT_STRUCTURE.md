## 3. Page Definition Registry

Этот registry является обязательным pre-implementation gate. `Index: yes` означает
планируемую индексацию только после прохождения индивидуального `Content Gate`.
Не пройденный gate = страница не публикуется, не входит в sitemap и не заменяется
тонким шаблонным текстом.

### PAGE-001 — Главная

- **URL:** `/`
- **Primary Intent:** познакомиться с инвестиционным бюро и выбрать следующий путь.
- **Secondary Intent:** перейти к регионам, объектам, методике или аналитике.
- **H1:** `Курортная недвижимость для инвестиций — с понятной экономикой и рисками`
- **Коммерческое сообщение:** не весь рынок, а ограниченный пул проектов, по которым бюро может объяснить цифры, риски и сценарий выхода.
- **Блоки:** Hero → задачи капитала → сложность выбора → стандарт отбора → Evidence Layer → регионы → отобранные проекты → пример паспорта → аналитика → команда → финальный CTA.
- **Обязательные данные:** четыре региона; 4–6 проектов; критерии отбора; дата актуальности; путь после заявки.
- **Объекты:** карточки регионов, Project cards, пример Project Passport.
- **Доказательства:** опубликованная методика, источники проектов, реальные эксперты; цифры и кейсы только после проверки.
- **Внутренние ссылки:** federal hub, четыре региона, `/obekty/`, `/metodika/`, `/analitika/`, `/podbor/`.
- **Primary CTA:** `Получить инвестиционный разбор`; secondary — `Сравнить регионы`.
- **Index:** yes.
- **Content Gate:** готово позиционирование, минимум 4 полных паспорта, методика и подтверждённые сведения о команде.

### PAGE-002 — Федеральный инвестиционный хаб

- **URL:** `/investicionnaya-nedvizhimost/`
- **Primary Intent:** выбрать курортный рынок для инвестиций.
- **Secondary Intent:** сравнить форматы, бюджеты, управление и риски.
- **H1:** `Инвестиционная недвижимость на курортах России`
- **Коммерческое сообщение:** сравниваем Сочи, Крым, Архыз и Алтай по единой логике, чтобы сузить выбор до подходящего рынка и проектов.
- **Блоки:** Hero → критерии сравнения → четыре рынка → продуктовые форматы → сценарии инвестора → общие риски → shortlist → методика → аналитика → CTA.
- **Обязательные данные:** сопоставимые бюджеты, сезонность, форматы, модель управления, ключевые риски и verifiedAt по каждому рынку.
- **Объекты:** Region comparison, Project cards.
- **Доказательства:** источники рыночных данных и ссылки на полные паспорта.
- **Внутренние ссылки:** четыре region hub, проекты, методика, статьи сравнения, подбор.
- **Primary CTA:** `Сравнить регионы`; secondary — `Получить разбор задачи`.
- **Index:** yes.
- **Content Gate:** все четыре рынка описаны в одной методологии; минимум по одному реальному проекту на рынок либо честная отметка об отсутствии shortlist.

### PAGE-003 — Сочи

- **URL:** `/investicionnaya-nedvizhimost/sochi/`
- **Primary Intent:** купить недвижимость в Сочи, предварительно оценив рынок как инвестицию.
- **Secondary Intent:** сравнить квартиры, новостройки, апартаменты и Адлер.
- **H1:** `Купить квартиру в Сочи для инвестиций`
- **Коммерческое сообщение:** помогаем выбрать не «любую недвижимость Сочи», а формат и проект с объяснимой экономикой, управлением и выходом.
- **Блоки:** Hero → выбор сегмента → районы → бюджет входа → спрос/сезонность → управление → риски → shortlist → сравнение с Крымом → FAQ → CTA.
- **Обязательные данные:** диапазоны бюджета, районы, форматы, сезонность, модель управления, ограничения и verifiedAt.
- **Объекты:** 3–6 сочинских Project cards.
- **Доказательства:** паспорта проектов, источники по цене/спросу, документы девелопера и оператора.
- **Внутренние ссылки:** PAGE-004, 005, 006, федеральный hub, Крым, сочинские проекты и статьи, подбор.
- **Primary CTA:** `Получить подборку по Сочи`; secondary — `Выбрать сегмент`.
- **Index:** yes.
- **Content Gate:** уникальный market overview и минимум 3 полных паспорта разных форматов; текст не дублирует дочерние страницы.

### PAGE-004 — Новостройки Сочи

- **URL:** `/investicionnaya-nedvizhimost/sochi/novostroyki/`
- **Primary Intent:** найти и сравнить новостройки Сочи для покупки.
- **Secondary Intent:** оценить девелопера, стадию, срок сдачи и стратегию выхода.
- **H1:** `Новостройки Сочи для инвестиций`
- **Коммерческое сообщение:** показываем только новостройки, прошедшие инвестиционный и документальный отбор.
- **Блоки:** Hero → критерии допуска → shortlist → сравнение стадий → девелоперы/документы → экономика входа → управление → exit → риски → FAQ → CTA.
- **Обязательные данные:** стадия, срок сдачи, девелопер, правовая модель, бюджет, платежный график, управление, стратегия входа/выхода, verifiedAt.
- **Объекты:** минимум 2 полных паспорта новостроек.
- **Доказательства:** проектные документы, сроки, источники цены, история девелопера; прогнозы помечены как сценарии.
- **Внутренние ссылки:** Сочи, апартаменты, Адлер, проекты, методика, релевантные статьи, подбор.
- **Primary CTA:** `Получить shortlist новостроек`.
- **Index:** yes.
- **Content Gate:** минимум 2 сопоставимых проекта и собственная сравнительная ценность; иначе блок внутри PAGE-003.

### PAGE-005 — Апартаменты Сочи

- **URL:** `/investicionnaya-nedvizhimost/sochi/apartamenty/`
- **Primary Intent:** купить апартаменты в Сочи.
- **Secondary Intent:** выбрать апартаменты для сдачи, управления или личного использования.
- **H1:** `Апартаменты в Сочи для инвестиций`
- **Коммерческое сообщение:** сравниваем не рекламную доходность, а формат, договор управления, расходы, личное использование и чистый сценарий.
- **Блоки:** Hero → форматы апартаментов → shortlist → gross vs net → оператор/договор → личное проживание → сезонность → статус и эксплуатация → сценарии → FAQ → CTA.
- **Обязательные данные:** статус, оператор, договор, комиссии, расходы, ограничения проживания, сезонность, сценарные расчёты, verifiedAt.
- **Объекты:** минимум 2 паспорта апарт- или сервисных проектов.
- **Доказательства:** договорная модель, тарифы/комиссии, источники загрузки и ставок; без гарантированной доходности без документа.
- **Внутренние ссылки:** Сочи, новостройки, Адлер, проекты, статья о чистой доходности, методика, подбор.
- **Primary CTA:** `Получить подборку апартаментов`.
- **Index:** yes.
- **Content Gate:** минимум 2 релевантных проекта и подтверждённые сведения об управлении; иначе не публиковать.

- **Внутренние ссылки:** PAGE-008..011, федеральный hub, Сочи, проекты, аналитика, методика, подбор.

- **Content Gate:** минимум 3 города с полной самостоятельной фактурой и минимум 4 паспорта; иначе сократить число дочерних страниц.

### 6.1. Core rule

> Один устойчивый поисковый интент — один основной индексируемый URL.

### 6.2. Index

Index:
- `/`;
- federal hub;
- regional/segment/local commercial pages from approved registry;
- `/obekty/`;
- full Project Passports;
- `/analitika/` and approved articles;
- `/metodika/`;
- `/podbor/`;
- `/o-kompanii/`;
- `/kontakty/`.

Noindex / exclude from sitemap:
- filter states;
- sort states;
- draft content;
- lots;
- technical routes;
- form success/error routes;
- privacy/consent;
- tag/category/author archives unless separately approved.

### 6.3. Canonical

- self-canonical for indexable pages;
- filtered `/obekty/` states canonical to `/obekty/`;
- one Project = one canonical path.

### 6.4. New URL Gate

Новый индексируемый city/segment/strategy URL разрешён только если есть одновременно:
1. самостоятельный SERP/search intent;
2. реальный ассортимент или самостоятельная аналитическая ценность;
3. уникальная экономика/риски;
4. собственные inbound/outbound links;
5. владелец данных и процесс актуализации.

### 6.5. Structured Data

- `BreadcrumbList` — для indexable hierarchy.
- `Article` — для аналитики.
- Organization/LocalBusiness — только при соответствии фактическим данным.
- `FAQPage` — только если FAQ видим и актуальные поисковые правила позволяют разметку.

Structured data обязана совпадать с видимым контентом.
